About {{ platform_name }}

{{ platform_name }} is a personal learning navigator built to solve one problem: students don't lack access to educational content — they lack a clear, trustworthy answer to "what should I do next?"

The platform combines a structured student profile ("Learning DNA"), an explainable recommendation engine, curated resource data, and project-based learning into one coherent loop: Discover → Understand → Plan → Learn → Practice → Build → Measure → Improve.

Built as a B.Tech IT capstone

The technology choices (Flask, SQLAlchemy, server-rendered templates) were made so the system is fully explainable in a viva, while the product experience is designed to the bar of an early-stage ed-tech startup. See docs/architecture.md for the full technical write-up.

What we never do

  • Fabricate ratings, reviews, user counts, or completion statistics.
  • Claim AI capabilities the platform doesn't actually have.
  • Rank a resource higher purely because it earns more commission.
